# FAC V3.x 第一阶段执行冻结基线 V1.0

状态：FROZEN  
适用：AEOS V7.2.2 / M09 FAC  
目标：将 FAC 从“财务核算系统”升级为“经营价值与财经自治中心”。

## 1. 总体原则

1. 财务始终站在财务视角：利润、现金、资产、负债、风险、投入产出。
2. 三化融合：自动化、精益化、信息化。
3. 数据处理优先级：自动获取 > 自动计算 > 规则推荐 > AI推荐 > 标准选择 > 自由输入。
4. 正式财务数值必须来自确定性代码、已批准规则或正式数据对象，LLM不得作为正式财务数值的计算来源。
5. 一套事实、多套口径、结果对账：经营账务、标准账务、税务口径分离。
6. 专业业务在专业系统操作；POMS管个人待办；EBMS管企业结果；M01管权限和决策；M02管数据和证据；M13管智能体。
7. Done ≠ Verified。财务闭环以价值验证为最终完成条件。

## 5. 订单财经五级状态

询价预测成本  
→ 报价确认成本  
→ 订单计划成本  
→ 动态预计实际成本  
→ 最终实际成本

每次计算必须形成独立 CalculationRun，历史不可覆盖。

## 6. 三化融合验收指标

- 重复录入率 = 0%
- 自动带出率 ≥ 80%
- 自动计算率 ≥ 85%
- 标准选择覆盖率 ≥ 90%
- 自由文本输入率 ≤ 10%

## 7. 第一阶段禁止项

首阶段不优先：
- 替代现有法定ERP总账
- 自动报税
- 自动银行付款
- 高风险自动调账
- 大量低价值Agent
- 纯展示型大屏
- 重复建设POMS任务管理

## 8. 第一阶段完成定义

第一阶段必须真实跑通：
询价 → 规格/BOM → 财经报价 → 正式报价 → 成交订单 → 动态成本 → 风险/机会 → 方案 → POMS → 反馈 → 复盘 → 财务价值验证。

本文件为第一阶段受控基线，后续变更需形成版本升级或变更记录。
