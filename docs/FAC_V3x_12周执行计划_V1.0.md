## P1 第2-3周：询价报价闭环

目标：
M05发起询价 → M04确认配置/规格/BOM → FAC自动核算 → M05正式报价。

必须实现：
- 自动带出客户、数量、币种、付款条件
- 自动带出规格书、BOM、工艺/包装
- 自动获取材料价格、工时、加工、历史品质、物流、FX
- 输出财务底价/目标价/建议价
- 输出预计毛利、现金、资金占用、风险
- 版本化报价财经结果
- 条件变化自动重算

验收：
3笔历史询价 + 1笔真实新询价端到端通过。

## P2 第4-5周：FAC-OFA订单财经升级

目标：
报价预测 → 计划成本 → 动态预计 → 最终实际 → 差异复盘。

必须实现：
- 五级成本状态
- CalculationRun
- BOM/材料价格快照
- 报价与实际毛利对比
- 材料/人工/品质/物流/汇率差异拆解

验收：
至少1笔已完工真实订单可解释最终毛利差异。
